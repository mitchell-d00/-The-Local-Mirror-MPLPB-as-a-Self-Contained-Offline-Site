Rules

  1. Every internal link is relative. ../spec/link_discipline.html, never an absolute filesystem path and never file:///. This is what survives the corpus being moved, zipped, or synchronized.
  2. Every page declares rel="index" and rel="up" in <head>. These are graph edges for the crawler, not decoration.
  3. Every page declares mplpb:status as current or retired. Retrieval filters on it.
  4. One directory per spoke, each with a scope declaration in its _index.html.
  5. Never delete. Retired pages move to _log/superseded/, flip to status: retired, and are named in the replacement's mplpb:supersedes. The filesystem audit still ingests them so the corpus retains its own history.

Adding a page

Copy this file, replace the mplpb: fields and the record card, write the body, then add one line to the parent Sub-Index. A page no index links to is an orphan — the validator reports it, and the crawler will not ingest it. Run tools/validate.py afterwards.
